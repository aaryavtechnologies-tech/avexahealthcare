## 🎨 Design Direction & Palette

- **Medical Teal (`#0D9488`, `#14B8A6`):** Health, hygiene, vitality, and precision
- **Light Blue / Sky (`#E0F2FE`, `#F0FDFA`):** Modern clean background gradients
- **Crisp White (`#FFFFFF`):** High contrast readability

## 🚀 Key Technical Features
- **Modern Web Guidance Compliant:** Native `<dialog>` elements for modals (`#homeCollectionModal`, `#reportDownloadModal`, `#lightboxModal`) with `overscroll-behavior: contain`, backdrop blur, accessible heading labelling, and light-dismiss fallbacks.
- **WhatsApp Integration:** Auto-generated dynamic pre-filled booking messages for tests, packages, and reports.
- **Zero-Dependency Static Fast Architecture:** Runs instantly in any environment with no heavy build overhead or disk exhaustion risks.
- **SEO & Schema.org:** Rich `MedicalBusiness` structured data JSON-LD on all pages.
- **Responsive Design:** Optimized across desktop, tablet, and mobile screens.
